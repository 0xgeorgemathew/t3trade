The signing bug & fix (the load-bearing detail)

Hyperliquid L1 actions use a phantom-agent EIP-712 signature over a hash of the msgpacked action. Two bugs surfaced during the live probes; both are fixed and unit-pinned.

Bug 1 — signature wire format (422 deserialization error)

I initially packed the signature as a flat 65-byte r‖s‖v hex string. The exchange expects an object: 

// WRONG (my first attempt):
"signature": "0x207613aa…01"

// CORRECT (what the exchange deserializes):
"signature": { "r": "0x…", "s": "0x…", "v": 27 }

Critically, v is 27 or 28 (Ethereum's recovery id + 27), not the raw 0/1. Fixed by adding signL1ActionForWire returning the object form with the v-bias.

Bug 2 — EIP-712 domain separator (recovered wrong address)

After bug 1, the exchange returned 200 but with "User or API Wallet 0xc343… does not exist" — it recovered the wrong signer address. Since the key provably derives to 0xB2b6…, the digest had to be wrong. Root cause: 

// WRONG (my domain separator):
chainId           → uint64BE(1337)           // 8 bytes
verifyingContract → raw 20 zero bytes

// CORRECT (standard EIP-712 ABI encoding):
chainId           → uint256(1337)            // 32 bytes, right-aligned
verifyingContract → address, left-padded to 32 bytes

EIP-712 encodes every uint as 32 bytes and every address as a 32-byte left-padded value. I had used the narrower uint64/20-byte forms. Fixed by adding uint256Be + addressTo32 helpers and the full EIP712Domain(string name,string version,uint256 chainId,address verifyingContract) type hash. After the fix, the live noop returned {"status":"ok"}.

The accepted algorithm (final, verified)

actionHash = keccak256(
    msgpack(action)          // insertion-order keys; undefined dropped;
                             //   out-of-int32 ints widened to bigint
  ‖ uint64BE(nonce)          // 8 bytes, big-endian
  ‖ (vault ? [0x01] ‖ addr20 : [0x00])
  ‖ (expiresAfter ≠ undefined ? [0x00] ‖ uint64BE(expiresAfter) : [])
)

digest = keccak256(0x1901 ‖ domainSeparator ‖ agentStructHash)
  domainSeparator = keccak256(EIP712DomainTypeHash ‖ keccak("Exchange")
                               ‖ keccak("1") ‖ uint256(1337) ‖ paddedAddr(0x0))
  agentStructHash  = keccak256(AgentTypeHash ‖ keccak(source) ‖ connectionId)
  source           = isTestnet ? "b" : "a"
  connectionId     = actionHash

signature = secp256k1.sign(digest, privateKey) → { r, s, v: 27|28 }
